# A separate product identity

Inspected the available RESTOPS checkout read-only: its README, Streamlit shell/view modules and `docs/screenshots/decision_workflow.jpg`. RESTOPS was not edited. The screenshot shows a persistent restaurant/state/month sidebar, charcoal/red metric containers and a large italic restaurant-investigation heading. Its strength is an operating-target and action-tracker workflow.

PULSE is deliberately distinct in both composition and interaction. Colour alone would not establish that distinction.

| Dimension | RESTOPS reference inspected | PULSE transformation |
|---|---|---|
| Information architecture | Nine management/restaurant views | Six destinations: Home, Signals, Investigate, Scenario Lab, Ask PULSE, Briefs; customer/operations/forecast evidence appears inside investigation |
| Navigation | Sidebar selects dataset, states, restaurants and month | Product bar and visible scope strip; exact signal context moves between destinations; scope controls are disclosed inside investigation |
| Opening | Restaurant/target metrics and decision-workflow entry | Morning view with governed health, non-overlapping exposure, a selectable twelve-week Pulse and a computed executive statement |
| Visual identity | Charcoal, red borders, italic motorsport headings, metric panels | Obsidian, graphite and silver with turquoise interaction; upright editorial hierarchy, open metric displays, tabular figures and restrained separators |
| Signal interaction | Restaurant operating gaps | Severity/domain/status feed with acknowledge, compare, questions and brief membership; direct timeline-event selection |
| Analytical journey | Target gap → restaurant investigation → proposed action | Signal → reference challenge → observed ledger → estimated exposure → benchmark → investigation path → conditional scenario → proposal → curated communication |
| Ask PULSE | Not shown as a corresponding hero workflow in the inspected RESTOPS shell | Globally accessible focused question panel; bounded intents, exact scope/period, evidence, method, limits and working follow-ups |
| Decisions | Action/experiment tracker and simulated outcomes | Explicitly unapproved session proposals; financial/service trade-offs and a guided case; no claim that pilots were executed |
| Simulation | Restaurant-specific operating assumptions | Nine governed independent assumptions; live base/scenario/delta rows, exact reset, retained inputs and saved consideration cases |
| Brief | Management report outputs | Select, order and remove findings; retain scenario/proposal scopes; real curated HTML and JSON downloads |

The turquoise/carbon palette draws on precision and engineering associated with modern motorsport. No Mercedes, AMG, Petronas or Formula One logos, team graphics, car imagery or affiliation claims are used. PULSE is an independent synthetic portfolio product.

The comparison is limited to the local RESTOPS files inspected, not an exhaustive review of all possible RESTOPS releases. Current PULSE screenshots and interaction evidence are in the [experience report](UI_UX_FINAL_REPORT.md) and [interaction audit](UI_UX_INTERACTION_AUDIT.md).
